# orbit.ops — 총무 업무 포털

총무 담당자가 구두·메신저 요청을 대신 접수하고 상태, 처리 메모, 변경 이력을 쌓는 포털입니다. 예시 실적 없이 빈 목록으로 시작합니다. 업무 보드·검색·CSV·누적 실적·팀장 조회 계정을 지원합니다.

## 로컬 개발

Node.js 24 이상이 필요하며 앱의 외부 패키지 의존성은 없습니다.

```sh
cd /workspace/kpi
npm start
```

기본은 `127.0.0.1:3000`이며 로그인 없는 로컬 개발 모드입니다. 로컬 데이터는 `data/orbit.sqlite`에 보존됩니다. `npm test`는 SQLite API 흐름과 배포 설정 검증을 실행합니다.

## 무료 운영 배포

**Render Free 서버 + Supabase Free PostgreSQL**을 사용합니다. 유료 디스크는 사용하지 않습니다. 전체 절차와 환경변수는 [DEPLOY.md](DEPLOY.md)에 있습니다. `render.yaml`은 무료 플랜과 필요한 변수를 명시합니다. 실제 서비스 연결 및 배포는 계정 생성 후 수행해야 합니다.

- `STORAGE_BACKEND=supabase`로 외부 DB를 선택합니다. 배포 환경은 관리자·조회 비밀번호와 DB 연결이 필수입니다.
- 로그인은 초기 버전의 HTTP Basic 인증입니다. HTTPS에서 `admin`은 변경, `viewer`는 조회만 허용합니다. 개인별 SSO는 아직 없습니다.
- `SUPABASE_SERVICE_ROLE_KEY`는 서버에만 두고 클라이언트나 Git에 넣지 않습니다.
- 등록·상태 변경·메모는 DB 함수에서 트랜잭션으로 저장합니다. 변경 이력 테이블의 수정·삭제를 트리거로 막고 공개 API 키의 RPC 호출을 차단합니다.
- Supabase 연결 오류 시 로컬 저장으로 전환하지 않습니다. 운영 데이터가 임시 디스크에서 사라지는 문제를 방지합니다.

## 기록과 기능 범위

요청 시각은 한국 시간으로 입력하고 등록·변경 시각은 서버/DB에서 기록합니다. 완료 후 재개 사유가 필요합니다. 업무 원문 수정·삭제 대신 메모로 정정합니다. 실적은 누적 기준, 소요 시간은 대기·주말을 포함한 요청부터 최종 완료까지의 시간입니다.

첨부파일, 팀장 확인·댓글, 월별 기간 필터, AI 요약, 개인별 인증은 후속 기능입니다. DB 관리자 권한 소유자의 변경까지 막는 외부 감사 시스템은 아닙니다. 무료 플랜에는 용량·유휴 중지 등 제한이 있어 실제 운영 전 공급자 조건과 백업 방식을 확인해야 합니다.

## PostgreSQL 계층 검증

기본 테스트는 외부 DB 테스트를 명시적으로 skip합니다. `@electric-sql/pglite`를 별도 테스트 위치에 설치하고 그 모듈 경로를 `ORBIT_PGLITE_PATH`로 지정하면 실제 PostgreSQL 호환 엔진에서 스키마 재실행, 공개 권한 차단, RPC 어댑터, 이력 보호, 트랜잭션 롤백을 검증합니다. 이는 실제 Supabase 클라우드 연결 검증을 대체하지 않습니다.

각 작업의 기존 격리 체크아웃을 사용하며 별도 Git worktree는 필요하지 않습니다.
