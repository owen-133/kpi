# overview

로그인 직후 처음 보이는 요약 화면이다. 위쪽에서 아래로 소개 배너, 네 칸 통계, 이번 달 운영 지표, 처리할 업무 목록, 완료율과 안내가 이어진다 (R-013, R-022).

사용 방법
- 처리할 업무 줄을 누르면 상세 창이 열린다 (R-006).
- 하위 업무가 있으면 완료 수와 전체 수를 표시하고 상세에서 체크한 결과를 목록에 반영한다 (R-036).
- 목록 아래 링크와 왼쪽 메뉴로 업무 보드·업무 실적·개선 이력으로 옮겨 간다.
- 이 화면이 열려 있고 창이 닫혀 있으면 30초마다 목록을 다시 불러온다 (R-013).
- 조회 계정은 같은 내용을 읽기만 한다 (R-007).
- 비어 있는 상태는 처리할 업무가 없다는 안내를 보여 준다.
