# edit-task

등록한 업무의 제목·요청자·부서·접수 경로·분류·중요도·요청일·기한·내용을 정정하는 창이다. 수정 사유가 필수이다 (R-031).

사용 방법
- 상세 창의 업무 수정 단추로 연다. 바꾼 항목과 사유는 업무 이력에 남고, 바뀐 것이 없으면 변경 없음 알림만 나온다.
- 같은 업무를 다른 곳에서 먼저 고쳤으면 저장이 거절되고 창 안에 이유가 나온다.
- 조회 계정에는 수정 단추가 없다 (R-007). 등록된 업무가 없는 상태에서는 열 수 없다.

사실 파일: edit-task.facts.json (4 변형, 9 상호작용)
